# Atualizador

IMS Toolkit — atualizador de aplicações e instalador de servidor RP Info.

Reescrito em C# / WPF (.NET 8), na pasta [`Atulizador/`](Atulizador/). Abra
`Atulizador/Atulizador.csproj` no Visual Studio (ou `dotnet build`/`dotnet run`
dentro da pasta) para compilar.

> A release publicada atualmente (`v3.01.00`) ainda é o build antigo em Python.
> Este código-fonte é a reescrita em C#, publicada aqui para revisão — nenhuma
> release nova foi criada a partir dele ainda.
